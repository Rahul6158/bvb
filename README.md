# Bonam Vinay Bhaskar (BVB) - Portfolio & Interview Preparation Suite

A clean, responsive, editorial reading web application for portfolio self-introduction and comprehensive technical, behavioral, and company preparation for **Data Extraction Engineer & Backend Systems** roles.

## 📄 Pages & Architecture

- **`index.html`**: Interactive, responsive Self-Introduction page.
  - Distraction-free article layout with highlighted section headings.
  - One-click text copy to clipboard.
  - Directly editable on-page with `localStorage` persistence and 1-click Reset.
  - Clean Light theme by default with Dark mode toggle.
  - Top navigation linking across all preparation suites.

- **`interview-questions.html`**: Technical interview preparation suite tailored for D.E. Shaw & high-scale backend systems.
  - **41 Categorized Technical Questions & Model Answers**:
    1. Resume Deep Dive & Project Experience
    2. Web Scraping & API Reverse Engineering
    3. Networking, HTTP, TLS & Anti-Bot Evasion
    4. Cloud Infrastructure, AWS (Lambda/SQS) & Distributed Systems
    5. Databases, SQL (Joins, Window Functions) & ETL Pipelines
    6. Python, Data Structures & Algorithms (DSA)
    7. Reliability, Monitoring (Grafana) & System Failure Handling
    8. Strategic Priority Matrix & Interviewer Drill-Down Chains
  - Instant live keyword search & category filter pills.
  - Fully copyable and editable with local persistence.

- **`behavioral-questions.html`**: Dedicated D.E. Shaw Behavioral, HR & Situational suite.
  - **24 Curated Questions & Proven Engineering Answers**:
    1. Motivation, Company Fit & Career Direction
    2. Strengths, Self-Awareness & Work Style
    3. Projects, Difficult Problems & Mistakes (SQS, Shopee, AWS)
    4. Teamwork, Disagreements & Handling Pressure
    5. Situational Scenarios & Salary Discussions
    6. Strategic Questions to Ask the Interviewer (Top 3 Choices)
    7. Master Preparation Strategy & Defending Resume Deep-Dives
  - Instant live keyword search & category filter pills.

- **`company.html`**: Detailed Company Knowledge & Context Profiles.
  - **D.E. Shaw Profile**: 45–60 second pitch, key facts (founded 1988, 750+ engineers, proprietary tech, Hyderabad/Bengaluru/Gurugram offices).
  - **Gamyam Infotech Profile**: Grounded, verifiable answers to "Tell me about your current company", public registry context, avoiding over-exaggeration.
  - **Key Interview Questions About Gamyam**: Company function, your exact role, Shopee project, reasons for leaving (growth-focused), and key lessons learned (scraper vs. production data extraction system).
  - **The 5 Core Verifiable Resume Anchors**: Shopee pipeline, Naver Lambda &rarr; EC2 migration, SQS + Redis duplicate-processing fix, AWS architecture, and the $15,000/month AWS cost optimization.

## 🚀 Getting Started

Simply open `index.html`, `interview-questions.html`, `behavioral-questions.html`, or `company.html` in any modern web browser. No external dependencies or build steps required.
